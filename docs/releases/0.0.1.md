# Simurgh 0.0.1

Initial experimental developer release notes, prepared 2026-10-09. This version is intended for local evaluation only.

## Included

- Grafana panel context capture with explicit series selection and confirmation, plus JSON export from the browser extension.
- Chromium and Firefox extension builds. The Firefox workflow was temporarily loaded and tested on Firefox 157.0.1.
- An experimental freehand selection path alongside Grafana's native time-range selection.
- A same-machine workspace for importing confirmed dashboard or reviewed source references, making bounded evidence reads, and keeping findings tied to inspectable evidence.
- Optional CPU-only local speech features. Codex-connected workflows use the operator's existing logged-in Codex session; this release does not provide or embed a separate Codex login.

## Known limitations

- The supported freehand instrumentation is experimental and pinned to Grafana 13.2.3 with uPlot 1.6.32. It is not qualified for other renderer versions.
- The Firefox 157.0.1 build is unsigned and was tested as a temporary development add-on. It is not a signed end-user install; do not disable Firefox signature enforcement.
- The Docker/Grafana setup and workspace are local-only development tools. The unsigned Grafana plugin is allowed only by the included local lab configuration. There is no hosted service or production deployment qualification.
- A real Grafana installation must configure and authorize its own exact origin. The test environment does not establish customer authorization, telemetry correctness, or deployment safety.
- Mobile touch drawing and physical microphone input have not been qualified. Browser width and platform results apply only to the documented test environments.
- The Codex workflow requires an already available user login and configuration; this release does not provision access.
- A moderate-severity dependency audit residual remains unresolved. This release does not claim a clean dependency audit or a completed security certification.

## Distribution status

This version is eligible only as an unsigned experimental GitHub prerelease after the gates in [CONTRIBUTING.md](../../CONTRIBUTING.md#release-policy) are met. Do not publish package artifacts to public registries or describe this version as production-ready or signed.

## Release archives

The expected release assets are `simurgh-chromium-0.0.1.zip`, `simurgh-firefox-0.0.1.zip`, `simurgh-grafana-0.0.1.zip`, and `simurgh-vscode-dev-0.0.1.zip`, together with `SHA256SUMS` and `release-manifest.json`. Each ZIP includes `LICENSE`, `NOTICE`, and [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md). GitHub's source-code archives provide the workspace and coordinator; the VS Code archive is for extension development and is not a VSIX.

Before extracting an archive, run `sha256sum -c SHA256SUMS` in the directory containing the downloaded assets. This checks that the files match the published checksums; it does not authenticate the publisher. `release-manifest.json` records the source commit and tree, but does not attest that ignored build outputs were freshly built from that revision. The release operator must build from the exact release commit and separately verify archive contents before publication. The archives are unsigned and no signature is claimed.

- Extract the Chromium ZIP to a directory, then load its extension root from `chrome://extensions` with Developer mode enabled.
- Extract the Firefox ZIP, then use **Load Temporary Add-on** at `about:debugging#/runtime/this-firefox`. Firefox removes the temporary extension on restart.
- Extract the Grafana ZIP into the local Grafana lab's plugin directory and restart Grafana. The unsigned plugin is supported only with the included local development allow-list; do not use that setting in a customer environment.
- Extract the VS Code development ZIP and point `--extensionDevelopmentPath` at its `simurgh-vscode-extension` root folder. It is not installable as a VSIX.
- Use the GitHub source archive and the [local MVP runbook](../../docs/local-mvp.md) to build and run the workspace/coordinator locally.
